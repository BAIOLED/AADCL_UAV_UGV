## 3. 外参与 TF

base_link→body：

| x | y | z | roll | pitch | yaw |
|---:|---:|---:|---:|---:|---:|
| +0.10 m | 0 | +0.15 m | 0° | +20° | 0° |

坐标约定：前、左、上。

| TF | 类型 | 唯一发布者 |
|---|---|---|
| map→odom | 动态 | wheeltec_global_localizer |
| odom→camera_init | 静态 | wheeltec_geometry_tf_publisher |
| camera_init→body | 动态 | FAST-LIO2 |
| body→base_link | 静态 | wheeltec_tf_manager |

实车验证：约 0.26 m 前进/倒车闭环后 Z 残差约 1.6 mm，保留 Pitch +20°。

## 4. 正式入口

| 模式 | 命令 |
|---|---|
| 建图 | roslaunch wheeltec_system_bringup wheeltec_mapping.launch map_name:=NAME |
| 保存 | 建图终端 Ctrl+C；退出后 rosrun wheeltec_map_tools finalize_map.py NAME |
| 定位 | roslaunch wheeltec_system_bringup wheeltec_localization.launch map_name:=NAME |
| 导航 | roslaunch wheeltec_navigation navigation_teb.launch map_name:=NAME |
| 基础链路 | roslaunch wheeltec_system_bringup wheeltec_livox_base.launch |

禁止同时启动 mapping 和 localization，禁止重复启动 Livox 或底盘节点。

## 10. 验收值

## 12. 故障矩阵

| 现象 | 诊断顺序 |
|---|---|
| 无雷达 | eth0→Ping→驱动节点→/livox/lidar |
| 无底盘 | lsusb→ttyACM0→udev→权限→节点 |
| FAST-LIO 无输出 | lidar→Livox IMU→初始化→配置 |
| TF 断开 | 缺边→发布者→时间→重复边 |
| NDT 不收敛 | 地图→frame→初值→外参→参数 |
| 有路径车不动 | /cmd_vel→/odom→串口→急停 |
| 地图不完整 | filtered_camera_init.pcd→finalize_map.py 输出→目录权限→磁盘 |
| 直行 Z 漂移 | Pitch→安装松动→地面→FAST-LIO 初始化 |
