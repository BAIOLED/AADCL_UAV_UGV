# 轮趣四轮差速机器人开发实施文档

> 用途：从一个空 ROS 工作空间复现当前轮趣小车系统。
> 写法：每一阶段明确“复制什么、打开什么、修改什么、编译什么、测试什么”。
> 平台：Jetson NX、Ubuntu 20.04、ROS Noetic、Livox Mid-360、轮趣四轮差速底盘。

## 2. 准备和复制源码

### 2.1 创建工作空间

~~~bash
ssh <SSH_USER>@<NX_MANAGEMENT_IP>
mkdir -p ~/livox_fastlio/src
cd ~/livox_fastlio
source /opt/ros/noetic/setup.bash
catkin_init_workspace src
~~~

### 2.2 复制四类基础源码

复制 Livox 驱动：

~~~bash
cp -a /path/to/livox_ros_driver2 \
  ~/livox_fastlio/src/livox_ros_driver2
~~~

复制 FAST-LIO2：

~~~bash
cp -a /path/to/FAST_LIO \
  ~/livox_fastlio/src/fast_lio
~~~

复制轮趣原生底盘包：

~~~bash
cp -a /path/to/turn_on_wheeltec_robot \
  ~/livox_fastlio/src/turn_on_wheeltec_robot

cp -a /path/to/wheeltec_robot_rc \
  ~/livox_fastlio/src/wheeltec_robot_rc
~~~

复制已经完成的轮趣适配包：

~~~bash
cp -a /path/to/wheeltec_stack/fast_lio_localization \
  ~/livox_fastlio/src/

cp -a /path/to/wheeltec_stack/wheeltec_* \
  ~/livox_fastlio/src/
~~~

开发电脑中的交付源目录为：

~~~text
D:\设备文档\WheelTech\wheeltec_stack
~~~

### 2.3 如果必须从 Scout 手工移植

只复制架构包：

~~~text
scout_tf_manager          → wheeltec_tf_manager
scout_cloud_adapter       → wheeltec_cloud_adapter
scout_pose_adapter        → wheeltec_pose_adapter
scout_pointcloud_mapper   → wheeltec_pointcloud_mapper
scout_map_tools           → wheeltec_map_tools
scout_navigation          → wheeltec_navigation
scout_system_bringup      → wheeltec_system_bringup
fast_lio_localization     → 保留包名
~~~

不要复制：

~~~text
scout_ros
ugv_sdk
Scout CAN 启动脚本
D435i 相机包和 camera_link TF
~~~

复制后在 package.xml、CMakeLists.txt、launch、config、scripts 和 src 中替换包名与节点前缀。最后检查：

~~~bash
rg -n "scout|agilex|ugv_sdk|D435|camera_link" \
  ~/livox_fastlio/src/wheeltec_*
~~~

结果必须为空。


## 5. 配置轮趣底盘

打开：



~~~bash

~~~

## 6. 配置 TF 和外参

### 6.1 打开静态外参

~~~bash
nano ~/livox_fastlio/src/wheeltec_tf_manager/config/extrinsics.yaml
~~~

写入：

~~~yaml
parent_frame: base_link
child_frame: body
x: 0.10
y: 0.00
z: 0.15
roll_deg: 0.0
pitch_deg: 20.0
yaw_deg: 0.0
publish_inverse: true
~~~

### 6.2 打开几何配置

~~~bash
nano ~/livox_fastlio/src/wheeltec_system_bringup/config/wheeltec_geometry.yaml
~~~

写入：

~~~yaml
odom_to_camera_init:
  x: 0.10
  y: 0.00
  z: 0.15
  roll_deg: 0.0
  pitch_deg: 20.0
  yaw_deg: 0.0
~~~

两处数值必须一致。完整 TF：

~~~text
map → odom → camera_init → body → base_link
~~~

唯一发布者：

| TF | 发布者 |
|---|---|
| map→odom | wheeltec_global_localizer |
| odom→camera_init | wheeltec_geometry_tf_publisher |
| camera_init→body | FAST-LIO2 |
| body→base_link | wheeltec_tf_manager |

## 7. 配置点云建图

打开：

~~~bash
nano ~/livox_fastlio/src/wheeltec_pointcloud_mapper/config/mapper.yaml
~~~

确认：

~~~yaml
scan_voxel_size: 0.05

radius_filter:
  enable: true
  radius: 0.15
  min_neighbors: 2

self_filter:
  enable: false
  min_x: -0.30
  max_x: 0.30
  min_y: -0.25
  max_y: 0.25
  min_z: -0.20
  max_z: 0.20

dynamic_filter:
  enable: true
  voxel_size: 0.20
  hit_probability: 0.70
  miss_probability: 0.40
  occupied_probability: 0.72
  clearing_probability: 0.35
  min_hit_scans: 8
  min_observation_span: 2.0
  ray_stride: 4
  max_clearing_range: 20.0
  ray_endpoint_margin: 0.30
  candidate_timeout: 5.0

map:
  voxel_size: 0.05
  max_voxels: 5000000
  autosave_period: 30.0
  save_on_shutdown: true
~~~

这里包含两个分辨率不同的栅格：`dynamic_filter.voxel_size` 是用于判定临时障碍的粗状态栅格，`map.voxel_size` 才是最终静态点云的精细栅格。端点命中提高占据概率，抽样射线穿过体素时降低占据概率，因此人员或车辆离开后，旧位置能从地图中清除。NX 上用 `ray_stride: 4` 和 `max_clearing_range: 20.0` 限制射线计算量。

映射器每 30 秒把已确认静态点自动写入 `filtered_camera_init.pcd`，正常 Ctrl+C 退出时还会再保存一次，不需要调用保存服务。建图进程退出后，再单独运行 `finalize_map.py`，把已完成的过滤 PCD 转换成 PCD、PGM、YAML 全套交付文件。

打开建图入口：

~~~bash
nano ~/livox_fastlio/src/wheeltec_system_bringup/launch/wheeltec_mapping.launch
~~~

按顺序确认：

1. include Livox msg_MID360.launch；
2. include fastlio_mapping_wheeltec.launch；
3. include pointcloud_mapper.launch；
4. include tf_manager.launch；
5. include pose_adapter.launch；
6. include turn_on_wheeltec_robot/base_serial.launch。

## 9. 配置导航

### 9.1 车体尺寸

打开：

~~~bash
nano ~/livox_fastlio/src/wheeltec_navigation/config/costmap_common.yaml
~~~

~~~yaml
footprint:
  - [0.25, 0.20]
  - [0.25, -0.20]
  - [-0.25, -0.20]
  - [-0.25, 0.20]
footprint_padding: 0.03
~~~

### 9.2 TEB

打开：

~~~bash
nano ~/livox_fastlio/src/wheeltec_navigation/config/teb_local_planner.yaml
~~~

~~~yaml
TebLocalPlannerROS:
  max_vel_x: 0.35
  max_vel_x_backwards: 0.15
  max_vel_y: 0.0
  max_vel_theta: 0.80
  acc_lim_x: 0.20
  acc_lim_theta: 0.30
  min_turning_radius: 0.0
~~~

轮趣原地转向角加速度较低，`move_base_teb.yaml` 和 `move_base.yaml` 使用 `oscillation_timeout: 20.0`、`oscillation_distance: 0.05`。不要沿用 Scout 的 `5.0 s / 0.20 m`：原地调头时平移量很小，会被外层 move_base 提前误判为振荡；应先给 TEB 自身的振荡恢复足够处理时间。

### 9.3 Livox 障碍源

打开：

~~~text
wheeltec_navigation/config/costmap_common.yaml
wheeltec_navigation/launch/navigation_teb.launch
~~~

确认：

~~~yaml
observation_sources: fastlio_cloud
fastlio_cloud:
  data_type: PointCloud2
  topic: /cloud_registered_body
  sensor_frame: body
  marking: true
  clearing: true
~~~

## 19. 外参运动验收

静态测试全部通过后才能运动，运动前必须通知现场。

~~~text
直行速度：0.05 m/s
持续：3 s
理论距离：0.15 m
angular.z：0
~~~

记录前后：

~~~bash
rostopic echo -n 1 /odom
rostopic echo -n 1 /Odometry
rostopic echo -n 1 /fastlio_odom
~~~

通过条件：

1. /odom 与 /fastlio_odom 的 X 同向、量级接近；
2. Y 很小；
3. Z 不随前进持续变化；
4. 前进/倒车闭环后 Z 回到初值附近。

本车实测闭环 Z 残差约 1.6 mm，保留 Pitch +20°。
